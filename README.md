# Study Dashboard

GitHub Pages용 개인 학업 관리 웹앱 프로토타입입니다.

현재 기능:
- D-Day 추가 / 삭제 / 자동 계산
- 가장 임박한 D-Day를 TODAY 영역에 크게 표시
- 할 일 추가 / 완료 체크 / 삭제
- 공부 기록
- 요일별 시간표
- 날짜 선택 캘린더
- 메모
- localStorage 저장

GitHub Pages:
1. Repository에 파일 4개를 업로드합니다.
2. Settings → Pages에서 Deploy from a branch를 선택합니다.
3. main / root를 선택합니다.
4. 저장 후 생성된 Pages 주소로 접속합니다.

데이터는 현재 브라우저의 localStorage에 저장됩니다.
